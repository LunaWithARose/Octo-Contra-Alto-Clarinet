# Octo-Contra-Alto-Clarinet

## Version one

* Range from Eb0 to potentially Eb4
* Bass saxophone reed
* Tenor saxophone pads
* Made up of nearly 25 body parts, connected by carbon fiber dowels and resin
* 100's of key parts, connected by carbon fiber rods.
* Cork tenons
* Clarinet keywork, no alternate fingerings.
* Bb, first register, second register are all seperate keys
* Currently only playable from middle A down to C
